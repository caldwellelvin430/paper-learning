# 证据强度与地学研究可补足之处

| 原文证据或缺口 | 本次分析 | 可实施改进（建议） |
| --- | --- | --- |
| §4.1 p.6称三独立专家并裁决，89小时 | 未报告裁决前一致率、κ/α、盲法及专家背景；最终共识不等于独立一致性 | 预注册成功手册、双盲独立标注，保留原始标签、不可判定和裁决；报告一致性与分歧原因 |
| §3.3 p.3写for each flagged instance，§4.1写审阅完整轨迹 | 是否只审可疑样本与496分母的抽样关系不够清楚 | 全量或预先分层随机抽样；分别披露筛查、抽样与最终分母；不要把定向错误搜集率当总体错误率 |
| 表3各基准模型与任务不同 | 难以将不同分歧率差异归因于评分器种类 | 同模型、固定轨迹的配对审计；跨基准结果分开报告，不直接排名 |
| §3.5 p.4把极差归因评价随机性，§4.4和A.2承认混合Agent变化 | 方法描述的强表述被实验设计与附录收窄 | 固定轨迹固定rubric重复Judge；固定轨迹重生rubric；最后才做完整Agent重跑，分层估计来源 |
| 表5与表3为不同任务和模型 | 95.5%与81.5%不是公平前后实验；p.9作者明确承认 | 同一条轨迹对比原、新评分器；以人工独立标签作参照；在留出任务验证 |
| §3.7声称修正组件，未给完整配对表 | 不能量化每个修复的收益或外溢错误 | 每种修复报告被修正病例及新引入的FP/FN；做消融与负例回归 |
| Tool-Veritas70任务、16领域、420评估 | 可能适配已知任务；没有独立外域充分验证 | 冻结规则与容差；独立领域、任务模板和产物格式做留出验证 |
| 表5零假阳性 | 仅说明观察到的420例中没有，不保证总体零误判 | 报告条件样本量与区间；使用独立错误产物和难负例测试 |
| 89小时／496任务≈10.8分钟 | 是否总专家人时及多轮裁决如何计入未细分 | 单独记初审、复审、裁决工时；估计复杂GIS任务成本；优先小规模可追踪试点 |
| p.9 Availability、当前源码复现边界 | 公开了实现，但权威逐轨迹导出仍未被本次证实 | 发布脱敏任务、产物、专家标签、评分器版本、变更日志，使结论可复算 |

另有呈现问题：表3的τ²一致率90.0%与101/112=90.18%并非同一精度；MCP-Atlas77/89=86.52%、Live66/95=69.47%，表中按整百分比显示后加一位小数。官方复现README解释此约定，不能把列内小数位误读为同等有效精度。采用计数重新计算可避免歧义。

本研究可改进的是抽样透明、独立判据、随机性分离、配对修复验证及领域产物验证。它们是设计要求和候选贡献方向；尚未发现地学实证缺陷前，不应把任何一项直接写成已实现创新。
