# 文献分类与导航维护

分类严格采用本目录保存的《文献分类与优先级规范》v1.0。唯一数据源为 [literature_catalog.yaml](文献元数据/literature_catalog.yaml)。CSV 和导航是导出物，不能分别手改。元数据中的分类理由、原文定位和研究判断由研究者核验填写；生成脚本不自动判断论文内容。

## 更新流程

1. 将新增论文按论文标题或短名放在 `论文翻译/` 下的新目录；现有论文保持原位。先核实英文摘要、任务定义、评价、实验与局限，区分 Benchmark、系统、训练数据和评价框架。
2. 在 YAML 的 `papers` 列表中新增一条唯一记录。`paper_id`、`paper_short_name`、`local_path`、`record_path` 不得重复。对照已有记录填写所有字段，给出独立的分类理由、阅读问题、证据位置及材料路径。原文不足时注明证据范围，不用中文译述代替原文核验。
3. 唯一主类别填 A–G，次要作用写 `secondary_tags`；阅读优先级 `reading_priority` 与实证可行性 `reproducibility` 独立填写。未核查完整任务/GT/评分器/环境链时保留 RU；实际运行并取得独立验证证据前不得授予 R0。
4. 中文稿范围按文内声明记录。摘要全译、主要章节译述、主文翻译和逐句全文不混称。缺少 PDF 时让 `pdf_paths` 为空列表，不编造文件名。资源五阶段和十项实证条件分别更新，注明核验日期、版本及未完成项。
5. 在仓库根目录运行以下命令。脚本会先检查唯一键、资料路径和规范哈希，再从同一 YAML 更新三个 README、七类导航、四份优先级清单、可行性矩阵、总索引及逐篇记录。

```powershell
python -m pip install -r scripts/requirements-literature.txt
python scripts/generate_literature_navigation.py
python scripts/generate_literature_navigation.py --check
python scripts/verify_literature_navigation.py
python scripts/test_literature_maintenance.py
```

`--check` 为只读检查，若 YAML 与导出物不同步或资料路径失效，会返回非零退出码。重复生成相同数据不会改变输出，不会追加重复记录。论文总数、各类别/优先级统计从 YAML 动态计算；脚本不固定为 52。验证器另外检查 YAML 与 CSV、三个首页、原有阅读链接及材料目录的一致性。

## 字段约定

| 字段组 | 主要字段及用途 |
|---|---|
| 书目信息 | `paper_title`、`paper_short_name`、`benchmark_name`、`year`、`publication`、`source_url`；Benchmark 不存在时写 N/A 并解释 |
| 研究分类 | `primary_category`、`baseline_category`、`classification_reason`、`research_role`、`research_value`、`secondary_tags` |
| 阅读管理 | `reading_priority`、`priority_reason`、`reading_focus`、`relevance_order`；同类别同优先级按相关性序号排列 |
| 评价研究 | `measurement_target`、`evaluation_mechanism`、`ground_truth_type`、`limitations_note` |
| 核验来源 | `original_source_file`、`verification_source`、`evidence_location`、`review_scope`、`verification_status`、`checked_on`；PDF 页码按物理页，其他以明确章节定位 |
| 实证管理 | `reproducibility`、`feasibility_reason`、`resource_check_items`、`open_source_status`、`resource_stages` |
| 阅读链接 | `local_path`、`chinese_materials`、`chinese_primary`、`translation_scope`、`english_materials`、`english_primary`、`pdf_paths`、`figure_paths`、`qa_paths`、`reading_notes` |
| 兼容已有导航 | `legacy_links` 保存原阅读导航目标，生成论文阅读页时继续提供这些入口；`record_path` 是自动生成的独立记录位置 |

CSV 每行对应一篇论文。列表和映射单元格采用 JSON 文本保存，布尔/数字等标量采用字符串导出；解码后与 YAML 比较。旧 `01_文献总索引.csv` 保持为同一 CSV 的兼容副本，不是第二数据源。

## 版本、分类调整与保护边界

本轮主类别完全沿用用户给定的 52 篇映射。以后如需改类，在 YAML 增加 `classification_changes`，逐条记录原类别、新类别、日期、原文证据与理由，再生成导航并更新变更说明。新增类别或改写规范须由研究者明确修订规范，不能由生成脚本自行决定。

本轮旧分类草案已由新索引替换；旧阶段报告与研究分析矩阵保留历史语境。Task01、Task02 的分析成果、所有论文子目录及教学文件不由本脚本改写。

2026-11-24 增量纳入九篇 Agent 评测文献，完整目录已达 61 篇。本轮逐篇重新核验英文，沿用候选的 B 类六篇、E 类三篇；包内每篇的 `文献分类记录.yaml` 原样保留为初始记录，不是当前数据源。当前状态以科研目录中的统一 YAML 及其导出记录为准。

去重检查包括规范化英文标题、短名、ID、路径、去版本号的 arXiv 标识、DOI，以及跨论文原始 PDF 的 SHA-256 指纹。不同论文恰有相同简称时，先核实标题和来源，再选用有区分度的短名，不能复制同一记录凑数。

生成脚本只写明列出的管理文件，不联网、不移动论文、不改变译稿及图片相对路径，也不调用 Git。提交或推送需另行操作；本次任务只完成本地修改和验收。
