# 构建严谨 Agent 基准测试的最佳实践｜文件说明

推荐阅读：`中文译文.md`。

- `中文译文.md`：摘要全文翻译与主要章节中文译文/译述；图表采用 `./images/` 相对引用。**并非严格逐句全文译本**。
- `英文原文_逐页完整提取.md`：全部原文 PDF 页的文本提取。
- `英文原文_保留版面.txt`：尽可能保留双栏布局的英文提取稿。
- `图表与逐页原稿索引.md`：按原稿页序放置全部图表、续表及逐页截图。
- `参考文献_原文.md`：英文书目所在页原样提取。
- `原始论文.pdf`：来源 PDF。
- `images/`：独立图表截图（含跨页续表）。
- `source_pages/`：原稿逐页 JPG 截图，可对照审稿。
- `QA_逐页核查.md`：每页存在性、图表数量、图片链接与翻译覆盖说明。
- `图表索引.json`：图表原始页码、位置及文件名机器可读索引。
