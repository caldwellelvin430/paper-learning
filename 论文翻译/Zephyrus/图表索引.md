## 图1 — 原文第 2 页

![图1](./images/figure-1-p002.png)

**Caption（原文）：** Figure 1: Overview: We develop ZEPHYRUS, an agentic framework for weather science. Given a query, the LLM-based agent ZEPHYRUS writes a code block which is sent to the code execution server. The server orchestrates several tools to execute the code block and returns the execution results to the agent. The agent either decides to execute more code to refine its output or respond back to the user. Refer to Appendix A.3 for the full prompt.

![图3](./images/figure-3-p007.png)

**Caption（原文）：** Figure 3: Semi-synthetic task generation pipeline: Weather-related texts are processed by a claim extraction agent to identify scientifically meaningful observational claims. Verified claims are transformed into reusable templates and manually reviewed. Code is generated by an LLM and verified by humans to validate each sample from a template against ERA5 meteorological data. We combine the verifier code with the templates and WeatherBench data to produce novel samples.
