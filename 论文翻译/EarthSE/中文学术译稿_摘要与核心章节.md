# EarthSE：评价大型语言模型地球科学探索能力的基准

> **翻译范围说明**：摘要为完整中文翻译；正文为主要章节译述，尚未覆盖原文及附录的全部段落。完整英语原文与截图另附。

## 原文摘要｜完整中文翻译

大语言模型（Large Language Models，LLMs）的进步推动了人们对科学应用的兴趣，也使得建立地球科学等特定领域评测基准成为必要。现有基准要么侧重一般科学问题，缺乏地球科学的领域特性；要么只覆盖孤立的子领域，缺少整体性的评价。此外，当前基准通常忽视模型开展开放式科学探索的能力。本文提出一个全面、专业的地球科学 Benchmark，用于评价大语言模型在这一领域从基础到高级阶段的科学探索能力。基于十万篇研究论文构建的语料库，作者首先建立两个问答数据集：Earth-Iron 具有广泛的问题覆盖面，服务于全面评价；Earth-Silver 则具有更高的难度，用于测量专业深度。这些数据集覆盖地球五大圈层、114 个学科方向和 11 类任务，考察开展科学探索所需的基础知识能力。更重要的是，作者提出 Earth-Gold，并设计新的评价指标：该数据集由开放式、多轮对话构成，专门评价模型在科学探索中的深度与多样性，任务包括方法归纳、局限性分析和概念提出。对 11 个主流大语言模型的大量实验显示，当前模型在不同地球科学领域和任务上仍有明显局限，科学探索能力还有较大提升空间。数据发布于论文给出的 Hugging Face 平台。

## 研究动机｜节译

已有科学 Benchmark 常采用可判定正误的封闭式问答，但地球科学问题同时涉及大气、水文、岩石圈、冰冻圈和生物圈等学科。能够正确解释术语或完成计算，不意味着模型可以归纳科学方法、识别论文的局限并提出后续研究问题。作者因此将**基础知识测评**与**开放式科学探索测评**分开设计。

## 三层数据集与构建方式｜重点译述

- **Earth-Iron**：着重覆盖广度，面向不同地球科学圈层和多种任务类别建立较大规模的问答集合。
- **Earth-Silver**：选择难度更高、专业性更强的材料，评价模型能否理解高阶地球科学概念和推理任务。
- **Earth-Gold**：围绕论文内容构建多轮开放式对话，考察方法归纳、研究局限性辨析、概念提出等科学探索行为，而不是只检查单一标准答案。

论文从十余万篇论文中进行领域与质量筛选，结合文献元数据、引用情况、自动化构造流程和人工审核。地球五大圈层与 114 个研究方向构成分类基础；不同数据集分别服务于知识广度、专业深度和探索能力。

## 评测机制｜重点译述

EarthSE 的评测设计提醒我们：**测量对象发生变化时，评分协议也必须改变**。封闭式 QA 可采用答案匹配或正确性检验；开放式科学探索具有不同的合理路径，需要评价探索的质量、深度和多样性。对于 GeoAgent Benchmark 的研究，可以把 EarthSE 放在“领域科学能力基准”类别中，而不是直接与 GIS 工具链执行 Benchmark 混合排名。

## 核心学术术语对照

| 英文术语 | 中文译法 | 注释 |
|---|---|---|
| Benchmark | 评测基准 | 与数据集、任务集合、执行环境和评分协议区分 |
| Ground Truth (GT) | 参考真值、标准答案 | 可能是答案、代码、执行结果或轨迹，需按论文实际定义 |
| Agentic AI | 智能体人工智能 | 具有规划、工具操作、反馈利用等能力的系统 |
| Tool-Augmented Agent | 工具增强智能体 | 可调用外部 API、程序或领域工具的智能体 |
| Tool Calling | 工具调用 | 包含工具选择和参数绑定，而不只是文本中提及工具 |
| Workflow | 工作流 | 有依赖关系的操作流程 |
| Trajectory | 执行轨迹 | 动作、调用参数、环境反馈和可能的中间产物 |
| Geospatial Grounding | 地理空间锚定 | 将模型输出与实际地物、坐标、尺度、属性或数据对应 |
| Vision-Language Model (VLM) | 视觉语言模型 | 同时处理视觉输入和语言的模型 |
| Multimodal Large Language Model (MLLM) | 多模态大语言模型 | 支持多模态理解和推理 |
| Remote Sensing (RS) | 遥感 | 本研究语境中的对地观测数据分析 |
| Earth Observation (EO) | 地球观测 | 涵盖卫星、航空以及相关环境观测 |
| Retrieval-Augmented Generation (RAG) | 检索增强生成 | 通过外部信息检索增强生成和推理 |
| Semantic Similarity | 语义相似性 | 与正确执行并不等价 |
| Execution-Based Evaluation | 基于执行的评价 | 需要真实或受控的运行环境及验证标准 |
| Multiple-Choice Question (MCQ) | 多项选择题 | 不等同于多工具执行任务 |
| Multispectral | 多光谱 | 传感器多波段观测 |
| Synthetic Aperture Radar (SAR) | 合成孔径雷达 | 主动微波遥感成像方式 |
| Refined Caption | 改进图注 | 利用论文上下文补充的科学图注 |
