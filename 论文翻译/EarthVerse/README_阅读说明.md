# EarthVerse — 论文研读包使用说明

- 首先打开 [`中文学术译稿_重点章节.md`](./中文学术译稿_重点章节.md)，包含中文摘要、核心方法、主要指标、实验结果和图表。
- 严格核对英文原文时，打开 [`英文原文_逐页.md`](./英文原文_逐页.md) 或 [`英文全文_连续文本.txt`](./英文全文_连续文本.txt)。
- 查看各页原样、插图和图表位置，打开 [`逐页原文与图表对照.md`](./逐页原文与图表对照.md)。
- 单独找图表，打开 [`图表索引.md`](./图表索引.md)，图片在 `images/`。
- 参考文献英文提取见 [`参考文献_英文逐页保留.md`](./参考文献_英文逐页保留.md)。
- 对照机器 QA、页面联系表和裁图坐标：`QA_逐页与图表核查报告.md`、`qa/`。
- 原始论文在 `原始论文.pdf`；完整页图在 `source_pages/`。

**重要限制：** 原始 PDF 共 46 页，英文逐页原文已覆盖全部页码，原版图文保留完整。中文文件目前为重点章节人工学术译述，而非全文逐段翻译。不得把它当作已完成全文精校的正式译本。

使用相对路径引用图片，整体拷贝进 GitHub、Obsidian 等 Markdown 环境时，请保持 `images/`、`source_pages/` 与 MD 在同一论文目录下。
