# GeoAnalystBench：评估大语言模型空间分析工作流与代码生成能力的 GeoAI 基准

本目录是从用户提供的学术 PDF 生成的独立研读包。

**优先阅读：** `中文译文_全文.md`（GeoBenchX、GeoAnalystBench）或 `中文学术译稿_主文与补充材料.md`（HTAM）。中文为学术译述，不是逐段逐句的全篇翻译；HTAM 的超长补充材料以中文重点译述、完整英文文本和全页截图配合提供。

**英文完整性：** `英文原文_逐页.md`（按阅读顺序排版，图表插入）以及 `英文原文_原始提取.txt`（原始 PDF 文本流备查），后者包括所有可提取的参考文献文本。

**图表：** `images/` 中为单独截图；`source_pages/` 中的每一张 JPG 精确对应 PDF 的一页，构成所有矢量图、表格、公式和页眉页脚的视觉备份。

**索引与核查：** `图表索引.md`、`QA_逐页核查报告.md`、`qa/质量核验.json` 和联系表。原始 PDF 放在目录根部便于验证。
