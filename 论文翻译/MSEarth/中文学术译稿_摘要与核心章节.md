# MSEarth：面向地球科学现象发现的多模态基准

> **翻译范围说明**：摘要为完整中文翻译；其余正文属于重点章节译述，附录中的长提示词、详细示例和参考文献未逐条翻译。

## 原文摘要｜完整中文翻译

多模态大语言模型（Multimodal Large Language Models，MLLMs）的快速发展，为解决复杂科学问题带来了新的机遇。然而，由于缺乏能够反映地学推理深度与复杂性的评测基准，这类模型在地球科学领域——尤其是研究生层次的问题——仍未得到充分探索。现有数据集通常依赖合成数据或简单的图文配对，难以体现真实应用需要的细致推理。为解决这一问题，作者提出 MSEarth：一个从高质量开放获取学术文献中构建的多模态科学数据集及评测基准。它覆盖大气圈、冰冻圈、水圈、岩石圈和生物圈五大地球科学圈层，包含超过 28.9 万幅科学图像，并为这些图像编制经过改进的图注，使其包含原论文中的上下文讨论与推理信息。该基准支持科学图像描述、多项选择题以及开放式推理等任务，为开发和评价具有科学推理能力的多模态模型提供可扩展且高保真的资源。MSEarth 已公开发布，以支持后续研究。

## 科学图像为何不能只依赖原始图注｜节译

科学论文中的图表通常只在图注中给出数据对象和最基本的解释，而真正支撑科学结论的假设、证据、推理以及局限常分散在正文中。直接利用原始图注生成问答，可能只考察模型能否复述图表表面内容，并不能评价对科学现象的深入理解。

## 数据集构建｜重点译述

作者从多学科地球科学开放获取文献中提取大量科学图片，并将图题与正文中相关的解释内容结合，形成**改进图注（refined captions）**。改进图注不再只是图片说明，而是融入现象成因、变量关系、研究假设和结论语境。论文报告提取了 **289,891 张图像**，用于进一步构建科学图像描述、多项选择题和开放式问答等任务。基准覆盖的五大圈层分别是大气圈、冰冻圈、水圈、岩石圈和生物圈。

## 任务与评价｜重点译述

MSEarth 从**图像描述生成、客观选择题、开放式解释**三个方向测试多模态科学能力。论文比较原始图注与改进图注的作用，强调在生成问题时必须尽量保留原论文推理上下文，避免出现不依赖图像即可猜中的任务，或虽然形式复杂但证据不足的问题。

对于你研究的 Benchmark 可靠性审计，MSEarth 可以用作**科学答案的证据依赖性与任务有效性**案例。不过它主要评价多模态科学理解，并非以实时 GIS 工具执行状态作为核心 GT。

## 核心学术术语对照

| 英文术语 | 中文译法 | 注释 |
|---|---|---|
| Benchmark | 评测基准 | 与数据集、任务集合、执行环境和评分协议区分 |
| Ground Truth (GT) | 参考真值、标准答案 | 可能是答案、代码、执行结果或轨迹，需按论文实际定义 |
| Agentic AI | 智能体人工智能 | 具有规划、工具操作、反馈利用等能力的系统 |
| Tool-Augmented Agent | 工具增强智能体 | 可调用外部 API、程序或领域工具的智能体 |
| Tool Calling | 工具调用 | 包含工具选择和参数绑定，而不只是文本中提及工具 |
| Workflow | 工作流 | 有依赖关系的操作流程 |
| Trajectory | 执行轨迹 | 动作、调用参数、环境反馈和可能的中间产物 |
| Geospatial Grounding | 地理空间锚定 | 将模型输出与实际地物、坐标、尺度、属性或数据对应 |
| Vision-Language Model (VLM) | 视觉语言模型 | 同时处理视觉输入和语言的模型 |
| Multimodal Large Language Model (MLLM) | 多模态大语言模型 | 支持多模态理解和推理 |
| Remote Sensing (RS) | 遥感 | 本研究语境中的对地观测数据分析 |
| Earth Observation (EO) | 地球观测 | 涵盖卫星、航空以及相关环境观测 |
| Retrieval-Augmented Generation (RAG) | 检索增强生成 | 通过外部信息检索增强生成和推理 |
| Semantic Similarity | 语义相似性 | 与正确执行并不等价 |
| Execution-Based Evaluation | 基于执行的评价 | 需要真实或受控的运行环境及验证标准 |
| Multiple-Choice Question (MCQ) | 多项选择题 | 不等同于多工具执行任务 |
| Multispectral | 多光谱 | 传感器多波段观测 |
| Synthetic Aperture Radar (SAR) | 合成孔径雷达 | 主动微波遥感成像方式 |
| Refined Caption | 改进图注 | 利用论文上下文补充的科学图注 |
