# GeoContra：阅读与文件说明

## 主要文件

- `GeoContra_中文精读与核心内容译述.md`：完整中文摘要、核心正文与方法的中文详细译述、实验表格、部分公式、研究局限及图表说明。
- `GeoContra_英文全文逐页提取.md`：PDF **19** 页文字的逐页完整提取，并嵌入原稿页图，方便核对全部参考文献、附录、代码与脚注。
- `GeoContra_逐页图表与原稿对照.md`：按 PDF 页码插入检测到的 **16** 张原始图表/算法/代码清单截图，并提供每一页原稿截图。
- `QA_逐页与图片引用核查.md`：页数、图表索引、图片完整性与 Markdown 相对路径的检查记录。
- `images/`：从 PDF 原图裁切的 Figure/Table/Algorithm/Listing。
- `source_pages/`：完整原稿的逐页截图，供图表和双栏核查。
- `data_manifest.json`：机器生成的图表页码、边界框及页数统计。

## 重要说明：译文覆盖范围

**这批中文文档是完整摘要翻译与正文核心内容的详细中文精读稿，不是逐字逐句的全文译本。** 英文全文和所有附录资料没有被省略；只是其中的英文全部段落尚未一一翻译为中文。图内英文保留为原图，不重绘。

数学公式、长数据表、双栏阅读顺序和代码格式可能因 PDF 文字层提取产生视觉与排版偏差，最准确的核对依据是 `source_pages/` 中对应原稿页。

所有图像均使用相对路径 `./images/` 或 `./source_pages/`，解压后不改变相对目录结构即可在 Obsidian 阅读。
