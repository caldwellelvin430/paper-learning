# MapAgent：集成动态地图工具的分层地理空间推理智能体

> **翻译范围说明**：论文摘要完整翻译；正文为主要章节的翻译性梳理，不构成 27 页全文逐段精译。

## 原文摘要｜完整中文翻译

智能体人工智能通过支持复杂推理与工具使用，显著扩展了大语言模型（LLMs）的能力。然而，现有多数框架面向数学、编码或 Web 自动化等领域，对于需要空间推理、多跳规划和实时地图交互的地理空间任务往往表现不足。为应对这些问题，作者提出 MapAgent：一个采用自定义工具集和智能体执行框架的分层多智能体即插即用系统，用于支持与地图集成的地理空间推理。不同于将所有工具等同对待的扁平化智能体方法——这类方法在应对功能相近但细节存在差异的地理空间 API 时往往使大语言模型负担过重——MapAgent 将规划与执行分离。高层规划器把复杂查询分解为子目标，再交由专业化模块处理。对于地图服务等工具密集型模块，作者设计专用的地图工具智能体，以自适应的并行方式高效编排相关 API，获取所需地理空间数据；对于解决方案生成或答案提取等较简单的模块，则无需引入额外的智能体开销。这种分层设计降低了认知负担，提高工具选择准确性，并实现对相似 API 的精细协调。作者在 MapEval-Textual、MapEval-API、MapEval-Visual 与 MapQA 四个不同的地理空间 Benchmark 上进行评价，取得优于当前先进工具增强和智能体基线的结果。

## 地图服务推理的关键困难｜节译

地图服务 API 通常涉及地点搜索、附近检索、路线规划、地点信息和行程组织。某些调用可以并行执行，某些调用则必须严格依赖前一步返回的结果。一个简单的“最短路线—附近商店—时间窗口”需求，就可能涉及多种地理信息服务之间的顺序与参数绑定。如果统一把所有工具放在一个扁平列表中，模型很容易出现工具选择困难和参数混淆。

## MapAgent 架构｜重点译述

MapAgent 采用外层 Planner Agent 执行任务分解与模块选择，在内层把工具密集型查询交给 Map-Tool Agent。框架同时包括解决方案生成、答案提取和视觉地点识别等功能模块。作者进一步为地图业务封装不同层次的工具接口，使其能够协调邻近检索、行程与路线、地点详细信息等操作，并在合适的位置采用串行或并行执行。

## Benchmark 与评价｜重点译述

MapAgent 的主要贡献是分层地图工具编排方法，而不是提出一个专门面向遥感执行轨迹可靠性的全新 Benchmark。论文在四个地图推理数据集上以准确率为中心比较多种 Agent 架构，并通过消融与分析展示工具模块化对效果的影响。在构建你的评测矩阵时，MapAgent 应被归为**被评测的 Agent 系统/地图工具框架**，其使用的 MapEval 与 MapQA 才是对应的基准。

| 英文术语 | 中文译法 | 注释 |
|---|---|---|
| Benchmark | 评测基准 | 与数据集、任务集合、执行环境和评分协议区分 |
| Ground Truth (GT) | 参考真值、标准答案 | 可能是答案、代码、执行结果或轨迹，需按论文实际定义 |
| Agentic AI | 智能体人工智能 | 具有规划、工具操作、反馈利用等能力的系统 |
| Tool-Augmented Agent | 工具增强智能体 | 可调用外部 API、程序或领域工具的智能体 |
| Tool Calling | 工具调用 | 包含工具选择和参数绑定，而不只是文本中提及工具 |
| Workflow | 工作流 | 有依赖关系的操作流程 |
| Trajectory | 执行轨迹 | 动作、调用参数、环境反馈和可能的中间产物 |
| Geospatial Grounding | 地理空间锚定 | 将模型输出与实际地物、坐标、尺度、属性或数据对应 |
| Vision-Language Model (VLM) | 视觉语言模型 | 同时处理视觉输入和语言的模型 |
| Multimodal Large Language Model (MLLM) | 多模态大语言模型 | 支持多模态理解和推理 |
| Remote Sensing (RS) | 遥感 | 本研究语境中的对地观测数据分析 |
| Earth Observation (EO) | 地球观测 | 涵盖卫星、航空以及相关环境观测 |
| Retrieval-Augmented Generation (RAG) | 检索增强生成 | 通过外部信息检索增强生成和推理 |
| Semantic Similarity | 语义相似性 | 与正确执行并不等价 |
| Execution-Based Evaluation | 基于执行的评价 | 需要真实或受控的运行环境及验证标准 |
| Multiple-Choice Question (MCQ) | 多项选择题 | 不等同于多工具执行任务 |
| Multispectral | 多光谱 | 传感器多波段观测 |
| Synthetic Aperture Radar (SAR) | 合成孔径雷达 | 主动微波遥感成像方式 |
| Refined Caption | 改进图注 | 利用论文上下文补充的科学图注 |
