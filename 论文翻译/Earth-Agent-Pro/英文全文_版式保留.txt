Fig. 4. Earth-Agent-Pro Framework. (a) Skill-guided workflow planning uses a shared expert specification to constrain both workflow construction and
runtime argument grounding. (b) Workflow-centered structured memory couples the evolving workflow with provenance-aware accepted evidence, preventing
failed attempts from contaminating downstream execution. (c) Evidence-grounded execution and repair performs node-local correction and, upon persistent
failure or an evidence gap, preserves the successful prefix while revising only the affected workflow suffix. Together, these mechanisms enable traceable and
bounded adaptation without discarding valid execution progress.
