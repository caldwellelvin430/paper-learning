# Earth-Agent-Pro：面向真实世界全链路地球观测的智能体：阅读指南

本文件夹中：

- `中文译文.md`：**主要章节的中文学术翻译/译述**，包括摘要、方法和关键结果，原始图表嵌入相应的章节。
- `英文原文_逐页.md`：逐页完整提取的英文原文。
- `逐页原文与配图.md`：按原 PDF 页码对照文本和原图，方便查阅附录。
- `英文全文_完整提取.txt` 与 `英文全文_版式保留.txt`：原始文本两种提取排列，便于检索。
- `图表索引_原图.md`：全部检测到的 Figure/Table 图题与原始截图。
- `images/`：来自论文原稿的图表截图，UTF-8 Markdown 用相对路径引用。
- `source_pages/`：全部 18 页原稿截图，避免图表裁切导致无法追溯。
- `原始论文.pdf`：完整原稿。
- `QA_逐页核查.md`、两张 `QA_*视觉联系表.jpg`：核查与视觉自检记录。

**局限性**：这是中文主要内容译述加完整英文全文/原图的核对包。参考文献、全部附录的技术细节和个别原始提示词并未逐句翻译，不能视作严格逐字完整中文版。保留可执行代码原样，是为了避免改变可复现性。

下载 ZIP 后请整体解压，保持 `images/` 与 Markdown 文件处于相同相对结构，在 Obsidian、Typora 等应用中即可正常查看图片。
